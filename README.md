# rfq-from-emails

Turn a distributor's RFQ (request-for-quote) inbox into quote-ready
catalog lines, in two stages:

1. **extract** — read an `.eml` file, emit the verbatim line-item strings
   an inside sales rep would quote from (and nothing else).
2. **match** — for each string, resolve the catalog SKU and the quantity
   in that SKU's unit of measure, or abstain explicitly
   (`ambiguous` / `not_in_catalog` / `discontinued`) with candidates and
   a one-line reason.

Matching is a **constraint filter** over the catalog's attribute grid —
no string similarity, no embeddings, no fuzzy matching. When the customer
under-specifies, the system abstains rather than guessing. See
`CLAUDE.md` for the full design spec and `DECISIONS.md` for the design
memo and the known-broken list.

## Layout

```
rfq/            the package (pure stdlib, no runtime dependencies)
tools/          scorers, a generalization probe, a per-line trace tool
tests/          pytest suite
data/
  catalog.csv     ~470 SKUs: size / material / thread / length, uom + pack qty, price, status
  xref.csv        customer / competitor / legacy part numbers -> sku
  check_format.py validates output-file shape (scores nothing)
  eml_to_json.py  optional .eml -> JSON helper
  dev/            18 example emails + reference lines.json / answer_key.json
out/            committed outputs, regenerated by the commands below
```

The `data/` example set is synthetic — no real company, customer, or
person. Company names and the internal mail domain in the emails are
placeholders.

## Setup

```
pip install -r requirements.txt   # installs pytest; the rfq package needs nothing
```

Python 3.11+ (developed on 3.12). No OS-specific code.

## Commands

Run from the repository root:

```
python -m rfq extract --emails <dir> --out lines.json
python -m rfq match   --lines lines.json --out predictions.json
python -m rfq run     --emails <dir> --out predictions.json   # optional: extract | match in one pass
```

`match` accepts any file in the `lines.json` shape, whatever produced it.

Regenerate this repo's committed dev outputs:

```
python -m rfq extract --emails data/dev/emails --out out/lines.json
python -m rfq match   --lines out/lines.json    --out out/predictions.json
python -m rfq run     --emails data/dev/emails  --out out/run_predictions.json
```

## Verify

```
python data/check_format.py --lines out/lines.json --pred out/predictions.json
python tools/score_lines.py --pred out/lines.json --key data/dev/lines.json --detail
python tools/score_match.py --pred out/predictions.json --key data/dev/answer_key.json --detail
python tools/mutate.py --detail
python -m pytest tests/ -q
```

`tools/explain.py "20 x 1/2 90 elbows" --domain example.com` prints the
full parse, identifier-lookup attempts, attribute-filter trace, final
resolution, and quantity decision for a single line.
